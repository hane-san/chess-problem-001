# MATE / TWO — Chess Problem Lab

白の初手（Key）を探し、黒のすべての合法応手をシャドーとして攻略する、静的なチェス・プロブレムアプリです。現在は D. J. Shire 作の #2 問題を収録しています。

## ローカルで起動

```sh
npm ci
npm start
```

http://localhost:8000 を開きます。ビルドは不要です。GitHub Pages にもそのまま配置できます。実行時に外部CDNや外部フォントには接続しません。

## 操作

- 白駒と移動先を順番にタップ、または駒をスライドして着手。ドラッグ中は駒が指に追従し、指を離した場所から着地します。同じ駒をもう一度タップすると選択を解除できます。
- 初手を見つけたら、印の付いた黒駒を選択。矢印を使わず、残りの合法な移動先すべてに半透明の黒いシャドーを表示。
- シャドーをタップすると黒駒が実際に移動し、ほかの候補は薄い点線だけに。白の次の一手で詰ませる。
- 正解時は、全シャドーの局面で同じ白の着手（移動元・移動先・昇格）が実際に詰みになるか確認。該当する未攻略のシャドーをまとめて撃破します。例えば Qc3# で5体、Nd2# で2体を攻略できます。
- 王手の矢印 → 逃げ道がない理由 → 命中 → 駒のシルエットが6片に砕ける → 短い余韻 → 白と黒を自動で巻き戻す、の順に再生。選択画面では撃破した全シャドーが消えます。
- 誤答時は実際の黒の応手を再生。白が合法に逃げたり受けたりできる場合は、その一例も再生します。王の合法な逃げ先、各方向の利き、自駒による塞がりを表示します。「黒の利き」では全黒駒の支配範囲を表示し、黒駒タップで絞り込めます。
- 解説を約4秒表示したあと、不成立の白の着手を表すシルエットが砕け、余韻を置いて全着手を逆順に巻き戻します。「止めて読む」や表示切替・盤上操作で自動巻き戻しを停止できます。「巻き戻して再挑戦」で誤答前の正確な盤面に復帰します。
- 「応手へ」で分岐点へ。「応手一覧」から直接選択も可能。
- 「次のシャドーへ」は未検証の応手を優先。「全手順を再生」は全13手の検証後に使用可能。
- 駒ヒントは初期オン。正解の詰み手を持つ白駒だけが光り、オン・オフは保存します。「考え方」は別ボタンです。
- ヒント・詰みを見る・戻る操作は盤面のすぐ下。失敗の解説切替も盤面に隣接しています。320pxのiPhone相当の画面でも、最初の画面内で主要操作に届きます。
- 「再生 標準」を押すと「再生 速め」に切り替わり、設定を保存します。どちらの速度でも王手・包囲の説明、一括撃破、余韻と巻き戻しを再生します。途中の「演出を中断して戻る」でも攻略結果は保持します。
- BGMは初期オフ、効果音は初期オン。上部で独立して切り替えられます。「音を試す」は現在のオン・オフ設定を変更せず、確認音だけを再生します。BGMはこのアプリ向けに生成するオリジナルの曲で、外部音源を読み込みません。
- 矢印キーで盤上を移動し、Enter/Spaceで駒・移動先を選択。Escapeで選択解除。

iPhoneのセーフエリア、縦横両画面、ページ拡大に対応します。小さい画面ではページ全体をスクロールでき、操作欄や説明が切れません。SVGの駒は端末にかかわらず同じ形で表示されます。

誤答が常に白のチェックメイトになるわけではありません。解説は合法な逃げ・取り返し・合駒を示し、実際に白が詰まされた場合だけ白王の包囲として表示します。

黒の応手は、即詰み・王手・取りなどを優先する説明用の一例です。全局面のゲーム理論上の最善手を求めるエンジンではありません。「白の逃げ・受け」は合法手であり、直後に黒の一手詰みを残さないことも確認します。その後の長期的な勝敗を保証する表示ではありません。破壊はシャドーや不成立の着手の演出で、キングの捕獲などを盤面状態に追加しません。

## 保存と安定性

進み具合・盤面の向き・ヒント・音声・再生速度の設定は、このブラウザの `localStorage` に保存します。一括撃破の結果も演出前に保存するため、余韻の途中で再読み込みしても攻略済みの候補は復元されます。再読み込み時は合法なチェックポイントから再開します。保存が使えない場合も、その画面で解き続けられます。「はじめから」で問題の進み具合を消去し、音声・ヒント・速度などの設定は保持します。

着手・反証・巻き戻し・全手順再生は一つの操作キューで管理します。リセット時には保留中の操作を無効にし、古い処理が盤面や説明を上書きするのを防ぎます。隠れた結果画面はフォーカスや操作を受け取りません。

盤面の64マスと変わらないSVG駒、応手一覧のボタンは再利用します。音声状態の更新は音声欄だけに反映し、盤面や応手一覧のフォーカスを外しません。ドラッグ描画は画面更新に合わせてまとめ、キャンセル・反転・リセット時に追従用の駒を除去します。バックグラウンド化やSafariのアニメーション停止からも合法なチェックポイントへ戻ります。

## データと構成

- `index.html` / `styles.css`: 画面とレスポンシブデザイン
- `lab-v2.js`: 状態、入力、描画、保存、アニメーション
- `tactics.js`: 合法な反証、王の逃げ道、駒の支配範囲と解説
- `soundscape.js`: BGM、効果音、iPhoneの音声起動と独立した確認音
- `data/problems.js`: FEN、初手、代表変化、解説、出典
- `vendor/chess.js`: 固定バージョン chess.js 1.4.0（ライセンス同梱）
- `assets/icon.svg`: アプリアイコン

合法手と詰み判定は chess.js を使用します。黒の応手はすべて合法手から生成し、各応手の実際の詰みを検証します。現在は1問の #2 専用で、問題選択や詰将棋のルールには対応していません。

chess.js の更新時は `npm run vendor:chess` で同梱ファイルとライセンスを同期してください。`npm run check:vendor` がロック済み依存との差異を検出します。

## 検証

```sh
npm ci
npx playwright install --with-deps chromium webkit
npm test
```

データ検証では初手の唯一性、全13応手への詰み、代表変化と紛れの反証を確認します。単体テストでは全13応手の詰み、完全に一致する着手だけの一括撃破、白の合法な生存例、王の移動で開く利き、Fool’s mateの白王包囲、反証の正しさ、利きの遮断を確認します。ブラウザテストはiPhone相当のWebKit・Chromiumとデスクトップで、全シャドーの攻略と消去、5体同時の破壊と余韻・巻き戻しの順序、誤答の自動巻き戻しと停止、白の逃げ・受け、余韻中の再読み込み、反転時の矢印、ヒント設定、捕獲の復元、再生、途中再開、操作中のリセット、保存失敗、キーボード操作を確認します。ドラッグの追従とキャンセル、盤面要素の再利用、音声更新中のフォーカス、確認音とミュート変更の競合、速度の保存と詰み解説の維持も検証します。320〜430pxの画面幅・横画面・文字拡大で、表示のはみ出しと主要操作の画面内への収まりを確認します。WebKitは自動テスト用のSafari系エンジンであり、iPhone実機の確認を代替するものではありません。

シャドー選択と全13手のブラウザスモークは `npm run test:smoke` で実行できます。Pagesのワークフローもロック済み依存と両ブラウザを使用し、検証後に公開します。
