# MATE / TWO — Chess Problem Lab

白の初手（Key）を探し、黒のすべての合法応手をシャドーとして一体ずつ攻略する、静的なチェス・プロブレムアプリです。現在は D. J. Shire 作の #2 問題を収録しています。

## ローカルで起動

```sh
npm ci
npm start
```

http://localhost:8000 を開きます。ビルドは不要です。GitHub Pages にもそのまま配置できます。実行時に外部CDNや外部フォントには接続しません。

## 操作

- 白駒と移動先を順番にタップ、または駒をスライドして着手。
- 初手を見つけたら、印の付いた黒駒を選択。矢印を使わず、残りの合法な移動先すべてに半透明の黒いシャドーを表示。
- シャドーをタップすると黒駒が実際に移動し、ほかの候補は薄い点線だけに。白の次の一手で詰ませる。
- 正解時は撃破演出 → 白と黒を自動で巻き戻し → 攻略済みシャドーを消去。タップ待ちの結果画面を挟まず、次の候補に進めます。
- 誤答時は実際の黒の応手を再生し、局面を止めて解説。王の合法な逃げ先、各方向の利き、自駒による塞がりを表示します。「黒の利き」では全黒駒の支配範囲を表示し、黒駒タップで絞り込めます。
- 解説の「元の局面でもう一度」で誤答前の正確な盤面に復帰。
- 「応手へ」で分岐点へ。「応手一覧」から直接選択も可能。
- 「次のシャドーへ」は未検証の応手を優先。「全手順を再生」は全13手の検証後に使用可能。
- 駒ヒントは初期オン。正解の詰み手を持つ白駒だけが光り、オン・オフは保存します。「考え方」は別ボタンです。
- 矢印キーで盤上を移動し、Enter/Spaceで駒・移動先を選択。Escapeで選択解除。

iPhoneのセーフエリア、縦横両画面、ページ拡大に対応します。小さい画面ではページ全体をスクロールでき、操作欄や説明が切れません。SVGの駒は端末にかかわらず同じ形で表示されます。

誤答が常に白のチェックメイトになるわけではありません。解説は合法な逃げ・取り返し・合駒を示し、実際に白が詰まされた場合だけ白王の包囲として表示します。

## 保存と安定性

進み具合・盤面の向き・効果音設定は、このブラウザの `localStorage` に保存します。再読み込み時は合法なチェックポイントから再開します。保存が使えない場合も、その画面で解き続けられます。「はじめから」で問題の進み具合を消去します。効果音は初期状態でオフです。

着手・反証・巻き戻し・全手順再生は一つの操作キューで管理します。リセット時には保留中の操作を無効にし、古い処理が盤面や説明を上書きするのを防ぎます。隠れた結果画面はフォーカスや操作を受け取りません。

## データと構成

- `index.html` / `styles.css`: 画面とレスポンシブデザイン
- `lab-v2.js`: 状態、入力、描画、保存、アニメーション
- `tactics.js`: 合法な反証、王の逃げ道、駒の支配範囲と解説
- `data/problems.js`: FEN、初手、代表変化、解説、出典
- `vendor/chess.js`: 固定バージョン chess.js 1.4.0（ライセンス同梱）
- `assets/icon.svg`: アプリアイコン

合法手と詰み判定は chess.js を使用します。黒の応手はすべて合法手から生成し、各応手の実際の詰みを検証します。現在は1問の #2 専用で、問題選択や詰将棋のルールには対応していません。

chess.js の更新時は `npm run vendor:chess` で同梱ファイルとライセンスを同期してください。`npm run check:vendor` がロック済み依存との差異を検出します。

## 検証

```sh
npm ci
npx playwright install --with-deps chromium webkit
npm test
```

データ検証では初手の唯一性、全13応手への詰み、代表変化と紛れの反証を確認します。単体テストでは全13応手の詰み、王の移動で開く利き、Fool’s mateの白王包囲、反証の正しさ、利きの遮断を確認します。ブラウザテストはiPhone相当のWebKit・Chromiumとデスクトップで、全シャドーの攻略と消去、通常速度の撃破演出、誤答の応手・利き・再挑戦、反転時の矢印、ヒント設定、捕獲の復元、再生、途中再開、操作中のリセット、保存失敗、キーボード操作を確認します。320〜430pxの画面幅・横画面・文字拡大で、表示のはみ出しと操作の到達性も確認します。WebKitは自動テスト用のSafari系エンジンであり、iPhone実機の確認を代替するものではありません。

シャドー選択と全13手のブラウザスモークは `npm run test:smoke` で実行できます。Pagesのワークフローもロック済み依存と両ブラウザを使用し、検証後に公開します。
